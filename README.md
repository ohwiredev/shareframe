# Shareframe

![Shareframe Cover](docs/shareframe-cover.png)

**Shareframe** is a fast, client-side Open Graph image editor built with React, TypeScript, Tailwind CSS, and Canvas 2D. It lets you create and export clean, pixel-perfect **1200 × 630** social preview images with custom background colors/gradients, logos, titles, and typography in seconds.

---

## ✨ Features

- 🎨 **Background Styling**: Solid color presets + custom color picker and curated gradient background presets.
- 🖼️ **Logo Integration**: Upload custom logos with real-time scale, positioning, and layout controls.
- ✍️ **Typography Control**: Independent font family, font size, text color, and weight settings for titles and descriptions.
- ⚡ **Live Canvas Preview**: Instant 1200×630 canvas preview powered by an optimized rendering pipeline.
- 📥 **Flexible Export Formats**: High-quality export support for **PNG**, **JPG**, and **WebP** images directly from the browser.
- 🔒 **100% Client-Side**: No server required—your images and assets stay strictly in your browser.

---

## 🛠️ Tech Stack

- **Framework**: Vite + React
- **Language**: TypeScript
- **Styling**: Tailwind CSS & shadcn/ui
- **Rendering Engine**: HTML5 Canvas 2D / OffscreenCanvas worker

---

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

---

## 📜 Available Scripts

- `npm run dev` – Starts the local development server.
- `npm run build` – Builds the production bundle (`tsc` + Vite build).
- `npm run lint` – Runs the linter (`oxlint`).
- `npm run check` – Runs linting and build checks.
- `npm run preview` – Previews the production build locally.
